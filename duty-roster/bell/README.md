# 🔔 กระดิ่งปลุกเวรแก้ไฟ — กล่อง ESP32 หน้าห้องเวร

กล่องถามระบบตารางเวรทุก 10 วินาที ถ้ามีงานรับแจ้งไฟดับนอกเวลาทำการ (16:30–08:30 และวันหยุด) ที่ยังไม่มีคนรับ → กระดิ่งดัง

| เวลา | กระดิ่ง / การแจ้ง |
|---|---|
| 0 นาที | ดังเป็นจังหวะ (3 วิ / หยุด 2 วิ) + LINE ถึงคนอยู่เวร |
| 3 นาที | ดังยาวต่อเนื่อง + LINE ซ้ำถึงคนอยู่เวร |
| 8 นาที | LINE ถึง หผ.ปร. / ชผ. "ยังไม่มีคนรับเรื่อง" |
| 20 นาที | กระดิ่งหยุด (เรื่องยังค้างในแอป) |

หยุดกระดิ่งได้ 3 ทาง: กดปุ่มใหญ่ที่กล่อง · กด "✋ รับงาน" ในการ์ด LINE · กด "รับทราบ" ในแอป (ตั้งค่า → กระดิ่งหน้าห้องเวร)

## อุปกรณ์ (ประมาณ 500–900 บาท)
- ESP32 DevKit 1 ตัว · โมดูลรีเลย์ 1 ช่อง (5V, ทนไฟ 10A 250VAC)
- ปุ่มกดดอกเห็ดใหญ่ (รับทราบ) · ปุ่มกดเล็ก (ทดสอบ) · LED แดง/ไฟกระพริบ (ไม่บังคับ)
- หม้อแปลง/อะแดปเตอร์ USB 5V · กล่องพลาสติก · กระดิ่งไฟฟ้า 220V

## ต่อสาย
| ESP32 | ต่อไปที่ |
|---|---|
| GPIO26 | IN ของรีเลย์ (VCC→5V, GND→GND) |
| GPIO27 | ปุ่มรับทราบ (อีกขา → GND) |
| GPIO14 | ปุ่มทดสอบ (อีกขา → GND) |
| GPIO25 | LED แดง + ตัวต้านทาน 220Ω → GND (ถ้ามี) |

ฝั่ง 220V: สายไฟเข้ากระดิ่งผ่านขา COM–NO ของรีเลย์ — **ให้ช่างไฟของ กฟส. ต่อ**

## ลงโปรแกรม
1. Arduino IDE → ติดตั้งบอร์ด ESP32 (Boards Manager: esp32 by Espressif) → เลือก "ESP32 Dev Module"
2. เปิด `bell.ino` ใส่ Wi-Fi และค่า `BELL_URL` / `BELL_KEY` จากแอป (ตั้งค่า → กระดิ่งหน้าห้องเวร → ⚙ ติดตั้งกล่อง ใส่ PIN)
3. Upload → ไฟบนบอร์ดติดค้าง = ออนไลน์ · ในแอปขึ้น "● ออนไลน์"
4. กด "🔔 ทดสอบ" ในแอป → กระดิ่งดังสั้น ๆ ภายใน 10 วินาที

ถ้ากล่องขาดการติดต่อเกิน 5 นาทีในช่วงเวลาปลุก ระบบส่ง LINE เตือน หผ.ปร.
