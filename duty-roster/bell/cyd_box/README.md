# กล่องกระดิ่งเวรแก้ไฟ — รุ่นจอทัช 2.8" (ESP32-2432S028 / HW-458)

เฟส 1 (ทดลอง): ใช้บอร์ดอย่างเดียว เสียบแค่ USB-C · มีเรื่องเข้า → จอแดงกะพริบ + ไฟ RGB แดง → แตะรับทราบ → เลือกชื่อ → LINE กลุ่มขึ้น "X รับทราบ" + QR เปิดงาน/โทรผู้แจ้ง

**ลงโปรแกรมแบบง่าย (ไม่ต้องคอมไพล์):** เปิด `https://aloofpea-aul.github.io/duty-roster/bell/flash/` ด้วย Chrome บนคอม

## ของบนบอร์ดที่ใช้
| ส่วน | ขา | ใช้ทำอะไร |
|---|---|---|
| จอ (ST7789 หรือ ILI9341) | SPI 13/12/14 · CS15 · DC2 · ไฟจอ 21 | แสดงผล — ตรวจสีจอเลือกชิปเองตอนเปิดครั้งแรก |
| ทัช XPT2046 | 25/32/39 · CS33 · IRQ36 | แตะรับทราบ / เลือกชื่อ |
| ไฟ RGB | 4 (แดง) 16 (เขียว) 17 (น้ำเงิน) | เขียวหรี่ = ปกติ · แดงกะพริบ = ปลุก · ส้ม = ออฟไลน์ · ฟ้ากะพริบ = ยังตั้งค่าไม่ครบ |
| เซนเซอร์แสง | 34 | ห้องมืด → จอหรี่ · ไฟห้องเปิดระหว่างปลุก → บันทึก "มีคนตื่น" |
| ปุ่ม BOOT | 0 | กด = รับทราบ · กดค้าง 3 วิ = จำลองเรื่องเข้า |

## ฝั่งระบบ
`gas/Requests.gs` → `boxPoll_` (GET `?action=box&k=KEY`) ทำงานคู่กับ `bellPoll_` เดิม — กล่องเก่า (`bell.ino`) ใช้ต่อได้ตามปกติ
- v1.8: ข้อความ OpenChat รอตรวจ (`oc` ในผลของ `box`) → แถบส้มหน้าเวร · ค้างเกิน `ocRemind` นาที (ค่าเริ่ม 30) → เด้งจอส้มกะพริบ (ไม่มีเสียง) · "ดูแล้ว"/BOOT = เงียบ 15 นาที
- `&ack=1&by=ชื่อ` รับทราบ · `&ev=light` ไฟห้องเปิด · `&rssi=-60` ความแรง Wi-Fi

## คอมไพล์เอง
- Arduino core **esp32 2.0.17** · บอร์ด ESP32 Dev Module · Partition Scheme **Huge APP**
- ไลบรารี: LVGL **8.3.11** · LovyanGFX **1.1.16** · ArduinoJson **7.x**
- คัดลอก `lv_conf.h` ไปไว้ข้างโฟลเดอร์ `lvgl` ในโฟลเดอร์ libraries
- ฟอนต์ `font_*.c` สร้างจาก IBM Plex Sans Thai (SIL OFL) เพิ่มรูปวรรณยุกต์ยกสูง/เยื้องซ้ายที่ U+F700–F716 — `thai.h` สลับให้อัตโนมัติ
