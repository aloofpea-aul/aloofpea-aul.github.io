ลงโปรแกรมกล่องกระดิ่งเวรแก้ไฟ (จอทัช)

บอร์ด ESP32-2432S028 (HW-458) · เวอร์ชัน 1.3 · เฟส 1 ทดลอง

ก่อนเริ่ม

  1. ใช้ Chrome หรือ Edge บนคอมพิวเตอร์ (มือถือ/iPad/Safari ใช้ไม่ได้)
  2. เสียบสาย USB-C จากบอร์ดเข้าคอม — ใช้สายที่ส่งข้อมูลได้ (สายชาร์จอย่างเดียวจะมองไม่เห็นบอร์ด)

ลงโปรแกรม

เบราว์เซอร์นี้ลงโปรแกรมไม่ได้ — เปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ ต้องเปิดหน้านี้ผ่าน https
กดแล้วเลือกพอร์ตที่ชื่อมี USB / CH340 / CP210x → Connect → Install · ครั้งแรกให้ติ๊ก ล้างข้อมูลในบอร์ด (Erase) · อัปเดตรุ่นใหม่ไม่ต้องติ๊ก (ค่า Wi-Fi/กุญแจอยู่ครบ) · ใช้เวลาราว 1–2 นาที

ถ้าไม่เห็นพอร์ต / เชื่อมต่อไม่ได้

  1. ลองสายเส้นอื่น หรือช่อง USB อื่นของคอม
  2. Windows อาจต้องลงไดรเวอร์ CH340 ก่อน (ค้นคำว่า "CH340 driver" จากเว็บผู้ผลิต WCH)
  3. กดค้างปุ่ม BOOT บนบอร์ด แล้วกด RST 1 ครั้ง ปล่อย BOOT แล้วกดติดตั้งใหม่

ลงเสร็จแล้ว — ทำตามจอบนบอร์ด

  1. ตรวจสีจอ — ถ้าช่องแดง/เขียว/น้ำเงินตรงชื่อ แตะจอ (หรือกด BOOT ค้าง 2 วิ) · ถ้าสีกลับด้าน กด BOOT สั้น ๆ
  2. เลือก Wi-Fi สำนักงาน แล้วพิมพ์รหัสบนแป้นในจอ
  3. ใส่กุญแจกล่อง 16 ตัว — ดูได้ในแอปงานเวรแก้ไฟ → ตั้งค่า → กระดิ่งหน้าห้องเวร → ติดตั้งกล่อง
  4. หน้าหลักขึ้น "ออนไลน์" สีเขียว = พร้อมใช้ · ลองกดค้างปุ่ม "จำลองเรื่อง" 3 วินาที เพื่อดูการปลุก

เฟส 1 ยังไม่มีเสียง — เวลามีเรื่องเข้า จอแดงกะพริบ + ไฟบนบอร์ดกะพริบแดง · LINE ยังไล่แจ้งตามขั้นเดิม
