เปิดระบบออกเลขหนังสือ →
เข้าระบบออกเลขใหม่แนบไฟล์ดู / แก้ไขค้นหาติดตั้งเป็นแอปเปลี่ยนผู้ใช้ถามบ่อย

สรุปสั้นที่สุด

  1. 1กรอก รหัสสำนักงาน (ครั้งแรกครั้งเดียว)
  2. 2แตะ ชื่อของคุณ → เริ่มใช้งาน
  3. 3กดปุ่มเขียว + ออกเลขใหม่ → กรอก → บันทึก ได้เลขทันที

🔑เข้าระบบครั้งแรก

ทำครั้งเดียวต่อเครื่อง ระบบจำไว้ 90 วัน เปิดครั้งต่อไปใช้ได้ทันที

1กรอกรหัสสำนักงาน

พิมพ์รหัสสำนักงาน แล้วกด เข้าใช้งาน

ไม่ทราบรหัส ขอได้จากผู้ดูแลระบบของสำนักงาน

2แตะชื่อของคุณ

เลือกชื่อ (พิมพ์ค้นหาได้) แล้วกด เริ่มใช้งาน

จากนี้ระบบจะ ใส่ชื่อผู้บันทึกและแผนกให้เอง ทุกครั้งที่ออกเลข

📝ออกเลขหนังสือใหม่

เลือกหมวดที่แถบด้านบน: ทั่วไป · สัญญา · คำสั่ง · ใบสำคัญ

3กดปุ่มเขียว

แตะ + ออกเลขใหม่ มุมขวาล่าง (บนคอมพิวเตอร์ ปุ่มอยู่ข้างช่องค้นหา)

4กรอกข้อมูล แล้วกดบันทึก

เลขที่หนังสือขึ้นให้อัตโนมัติด้านบน กรอกช่องที่มีเครื่องหมาย * ให้ครบ แล้วกด บันทึกข้อมูล

ถ้าเปลี่ยน วันที่ ไปปีหน้า เลขจะเริ่ม 001 ของปีนั้นให้เอง

5ได้เลขหนังสือทันที

จดเลขที่แสดงไปใช้ได้เลย รายการจะขึ้นเป็นรายการแรกในหน้ารายการ

หลายคนออกเลขพร้อมกันได้ เลขไม่ซ้ำแน่นอน ถ้าเลขที่เห็นมีคนใช้ไปก่อน ระบบจะให้เลขถัดไปและแจ้งบนหน้าจอ

📎แนบไฟล์ (สัญญาจ้าง / คำสั่ง)

หมวดสัญญา: ไฟล์สัญญา + ไฟล์เงินประกัน · หมวดคำสั่ง: เอกสารแนบไม่จำกัดจำนวน

แตะกรอบ + แตะเพื่อแนบไฟล์ / ถ่ายรูป เลือกไฟล์ในเครื่อง หรือถ่ายรูปเอกสารด้วยกล้องได้เลย (เลือกหลายไฟล์พร้อมกันได้)

รอให้ชื่อไฟล์ขึ้นเป็น ตัวสีม่วง (อัปโหลดเสร็จ) แล้วค่อยกดบันทึก

พิมพ์ รายละเอียดสัญญา / รายละเอียดหนังสือ เองได้ตามจริง

ไฟล์ละไม่เกิน 25 MB · รูปจากกล้องมือถือระบบย่อให้อัตโนมัติ
ถ้าขึ้น "อัปโหลดไม่สำเร็จ" กด ลองใหม่

👆ดูรายละเอียด / แก้ไข / เปิดไฟล์

แตะที่การ์ดรายการใดก็ได้

หน้ารายละเอียดจะเลื่อนขึ้นจากด้านล่าง แสดงข้อมูลครบทุกช่อง

กด แก้ไข เพื่อแก้ข้อมูล หรือแตะชื่อไฟล์เพื่อเปิดดูไฟล์แนบ

ใบสำคัญจ่ายมีปุ่ม จัดเก็บ และ แจ้งรับเงิน อยู่ในหน้านี้ด้วย

สัญญาจ้างแสดง จำนวนวันที่เหลือ ของสัญญาบนการ์ด (สีส้ม = เหลือไม่ถึง 30 วัน)

🔍ค้นหา

พิมพ์คำในช่องค้นหา เช่น เลขที่ ชื่อผู้รับจ้าง ชื่องาน หรือชื่อหมู่บ้าน

หน้ารายการแสดง 200 รายการล่าสุด แต่การค้นหาจะ ค้นรายการเก่าทั้งหมดให้เอง (พิมพ์ 2 ตัวอักษรขึ้นไป)

ลบคำค้นหา เพื่อกลับไปหน้ารายการล่าสุด

📲ติดตั้งไว้ที่หน้าจอโฮม (เปิดเหมือนแอป)

ทำครั้งเดียว ต่อไปแตะไอคอนเปิดได้ทันที เต็มจอ ไม่ต้องหาลิงก์

🍎 iPhone / iPad

  1. เปิดระบบด้วย Safari
  2. แตะปุ่มแชร์ ⬆︎ (ด้านล่างหรือมุมขวาบน)
  3. เลือก เพิ่มไปยังหน้าจอโฮม → เพิ่ม

🤖 Android

  1. เปิดระบบด้วย Chrome
  2. แตะเมนู ⋮ มุมขวาบน
  3. เลือก ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก
ไอคอนจะเป็นรูปเอกสารสีม่วง เขียนว่า "เลข"

👤เปลี่ยนผู้ใช้ / ออกจากระบบ

ใช้เมื่อเครื่องเดียวกันใช้หลายคน

แตะ รูป / ชื่อของคุณ ที่มุมขวาบน → เลือกชื่อใหม่ → เริ่มใช้งาน

ถ้าจะให้เครื่องนี้ต้องกรอกรหัสใหม่ กด ออกจากระบบเครื่องนี้

ปุ่มฟันเฟือง ⚙ (ตั้งค่าระบบ) สำหรับผู้ดูแลเท่านั้น ต้องใช้รหัสผู้ดูแล

💬ถามบ่อย

ทำไมระบบให้กรอกรหัสอีกแล้ว?

ครบ 90 วัน, ผู้ดูแลเปลี่ยนรหัสสำนักงาน, หรือใช้เครื่อง/เบราว์เซอร์ใหม่ (เปิดจาก LINE กับเปิดจาก Chrome นับเป็นคนละเบราว์เซอร์) กรอกรหัสใหม่ครั้งเดียวก็ใช้ต่อได้

ชื่อของฉันไม่อยู่ในรายชื่อ

แจ้งผู้ดูแลระบบให้เพิ่มชื่อในหน้าตั้งค่า (รายชื่อผู้บันทึก)

กดบันทึกแล้วขึ้นว่าเชื่อมต่อไม่สำเร็จ

ตรวจอินเทอร์เน็ต แล้วดูในรายการก่อนว่ารายการเข้าไปแล้วหรือยัง ถ้ายังไม่มีค่อยกดบันทึกอีกครั้ง (ข้อมูลในฟอร์มยังอยู่)

ออกเลขผิด แก้ได้ไหม?

แตะรายการ → แก้ไข แก้ได้ทุกช่อง รวมถึงเพิ่ม/เอาไฟล์แนบออก

ขึ้นปีใหม่ เลขเริ่มใหม่ไหม?

เริ่ม 001 ใหม่อัตโนมัติทุกหมวด ตามปีของ "วันที่" ในหนังสือ

ใครเปิดไฟล์แนบได้บ้าง?

ผู้ที่มีลิงก์ไฟล์ ซึ่งลิงก์แสดงเฉพาะในระบบที่ต้องใส่รหัสสำนักงาน ไม่ควรส่งต่อลิงก์ไฟล์ให้คนนอก

ระบบใช้ไม่ได้ ติดต่อใคร?

แจ้งผู้ดูแลระบบของสำนักงาน ระหว่างนี้ใช้ "เวอร์ชันสำรอง (Apps Script)" ที่ลิงก์ท้ายหน้าระบบได้ ข้อมูลเป็นชุดเดียวกัน
